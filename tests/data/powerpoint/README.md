# PowerPoint test files

Neutral example plots only.

- `Figures/`: two example plots (matplotlib), each saved as PNG, PDF and SVG, as R would save a
  figure's copies. Pictures from the deck and the copies relink to these.
- `example_deck.pptx`: four slides made with python-pptx from the PNGs, then opened and saved
  in PowerPoint for Mac 16.114. Slide 1 has a title ("Example figures"), slide 4 is hidden.
- `copied_slide.slides`: what PowerPoint put on the clipboard for a copied slide 2
  (com.microsoft.PowerPoint-14.0-Slides-Package). The names in its document properties were
  blanked.
- `copied_*.gvml`: what PowerPoint put on the clipboard for copied shapes from slide 2
  (com.microsoft.Art--GVML-ClipFormat): the rounded rectangle with text, the group, the picture
  and the line.
